# Research MCP

Research MCP exposes Research Loop as a protocol-aware MCP state/persistence layer.

It deliberately does **not** perform scientific reasoning. ChatGPT, Claude, or another reasoning client combines the current conversation with durable GitHub state, authors plans/analyses/critiques, and asks Research MCP to persist only allowed semantic operations.

## Architecture

```text
Current chat + durable GitHub state
             ↓
      reasoning client
             ↓
        Research MCP
             ↓
           GitHub
             ↑
   Coding Agent via git
```

## Tools

- `get_research_status()`
- `get_latest_run(status)`
- `load_planning_context()`
- `create_planned_run(name, plan, author, run_date?)`
- `load_analysis_context()`
- `read_run_file(run_path, relative_path, start_line?, end_line?)`
- `save_analysis(content, author, run_path?)`
- `load_critique_context()`
- `save_critique(content, author, run_path?)`
- `complete_run(run_path?)`

## Local setup

```bash
python -m pip install -e '.[mcp]'
export RESEARCH_GITHUB_REPO=YOUR_GITHUB_USER/YOUR_RESEARCH_REPO
export GITHUB_TOKEN=YOUR_FINE_GRAINED_TOKEN
research-mcp
```

For local HTTP testing:

```bash
research-mcp --transport streamable-http --host 127.0.0.1 --port 8000
```

The MCP endpoint is `/mcp`; liveness is `/healthz`.

OAuth is off by default. Do not expose auth-off HTTP mode to the public internet.

## Remote deployment

The recommended pattern is self-hosting per researcher/project:

```text
ChatGPT / Claude
      ↓ HTTPS + OAuth
Research MCP on Cloud Run or equivalent
      ↓ repo-scoped GitHub credential
Your research repository
      ↑ git pull / push
Coding Agent
```

Do not share a maintainer-operated MCP instance across unrelated users unless you intentionally implement multi-tenant credential isolation.

Use `research_mcp/.env.remote.example` as the environment-variable reference and `Dockerfile.research-mcp` for container deployment.

## Protocol guards

- At most one active non-`COMPLETED` run at a time.
- Plans are authored by the reasoning client, not generated by MCP.
- Analysis and critique are append-once through the normal protocol path.
- Analysis and critique authors must differ.
- Completion requires plan, raw summary, registered raw artifacts, analysis, and critique.
- `read_run_file()` is restricted to repository-relative files under `research_runs_history/`.
- First-time projects are supported: planning can bootstrap without a previous `COMPLETED` run.
