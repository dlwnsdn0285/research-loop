# Research Plan

Follow `RESEARCH_PROTOCOL.md` and `CLAUDE.md`. Find the latest completed/critiqued run, read `03_ANALYSIS.md`, `04_CRITIQUE.md`, relevant repository evidence, and the user's current request. Draft the smallest decisive experiment, defining conditions, controls, metrics, expected outcome branches, required raw artifacts, and a stop/expand rule. Explain the plan first. If plan-commit approval is enabled, do not create or modify the run until the user explicitly approves. After approval, create the next run with `00_MANIFEST.yaml` and `01_PLAN.md` at `PLAN_READY`.
